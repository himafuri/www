# Set ticket triage status

Use the status values below in each local Markdown ticket's `Status:` line.

| Canonical role    | Status value      | Meaning                                                   |
| ----------------- | ----------------- | --------------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer needs to evaluate the issue                  |
| `needs-info`      | `needs-info`      | The reporter needs to supply more information             |
| `ready-for-agent` | `ready-for-agent` | The ticket has enough detail for an agent to implement it |
| `ready-for-human` | `ready-for-human` | A human needs to implement the ticket                     |
| `wontfix`         | `wontfix`         | The maintainer has decided against implementation         |

When a skill names a triage role, use its status value from this table. Edit the status-value column to change the vocabulary.
